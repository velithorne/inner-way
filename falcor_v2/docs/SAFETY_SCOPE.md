# FALCOR v2 Safety Scope

## Software-Only

FALCOR v2 is **software-only**. It does **not**:

- Provide instructions to build real devices
- Recommend hardware configurations
- Endorse or facilitate construction of physical apparatus

## Virtual Assemblies

All "devices" are **parametric virtual assemblies** represented as JSON. They:

- Describe geometry, materials, and parameters for simulation
- Are generic and non-instructional
- Do not constitute blueprints or build guides

## Use Cases

- Reproducible simulation of known physics
- Measurement and falsification methodology
- Data analysis and audit artifacts
- Research and validation workflows

## No Cloud, No Telemetry

- No cloud connectivity
- No telemetry or data collection
- No external network dependencies

## Offline, Desktop

- Runs entirely on the user's machine
- No GPU required
- Windows 10/11 and Linux supported
