## Monster Soul - Digital Companion Game

A mobile game blending Digimon Tamagotchi care with Pokémon-style 3D turn-based battles. Create your monster from your face and personality!

**Location**: [`monster-game/`](./monster-game/)

```bash
cd monster-game && npm install && npm run dev
```
