# Origami Information Folding Engine

A structure-aware folding engine that compresses and reorganizes source-code projects as foldable information objects, preserving useful relationships while enabling controlled reconstruction and insight discovery.

## Phase 1 Goal

Build a prototype that accepts source-code folders and produces:

- a folded representation
- a fold ledger
- reconstruction output
- compression statistics
- structure-preservation metrics
- a visual/report summary

Phase 1 is focused on:

- Python
- JavaScript / TypeScript
- JSON / YAML
- Markdown / text

## Core Idea

Traditional compression asks:

- how do we store fewer bits?

Origami folding asks:

- how do we reshape information so hidden relationships become adjacent, layered, reusable, and recoverable?

## First 5 Operators
